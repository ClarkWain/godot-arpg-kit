# v0.2.0 — 可靠性与集成改进

发布日期：2026-10-10。本版本包含接入行为变化，升级前请阅读 [迁移指南](https://github.com/ClarkWain/godot-arpg-kit/blob/v0.2.0/docs/migration-v0.2.0.md)。

## feature

- 跨平台 Python 测试入口，PowerShell 与 CI 使用同一结果判定。
- Godot 4.5 / 4.6.3 CI 矩阵、官方下载 SHA-512 校验、独立日志与 JSON 汇总。
- 同步拾取入口、自定义接收回调、金币拾取通知。
- 背包、装备、任务恢复返回成功状态，新增背包与装备恢复通知。

## fix

- 修复任务管理器延迟创建和重建后的事件转发，以及读档旧实例回调与事件索引残留。
- 修复死亡掉落接入、父节点偏移、部分堆叠通知、重复/重入拾取和对象池生命周期。
- 统一背包装备转移入口，修复卸装失败、换装回滚和提交前通知。
- 隔离共享装备属性资源，修复损坏、修理及重复恢复引起的属性残留或叠加。
- 存档先校验后提交，加载失败保留当前状态；检查非法字段、重复身份和错误槽位，深拷贝嵌套数据。
- 修复测试泄漏，严格检查错误、退出码、超时和测试汇总。

## 升级注意

- 拾取信号是转移后的通知，旧回调中再次入包的逻辑需要删除或迁移到同步 `pickup_handler`。
- 实际 EquipmentManager 与背包需要双向引用；默认卸装缺少接收背包时失败并保留装备。
- 读档接口返回 `bool`，无效条目使整个模块恢复失败；先注册全部物品和任务定义。
- UI 使用 `inventory_restored` / `equipment_restored`；装备读档不触发装备、卸装和套装玩法事件。
- 各模块提供独立失败保护；整个角色联合恢复、跨模块重复身份检查与存档版本迁移仍由游戏协调。

## 验证

Godot 4.5 / 4.6.3 本地均通过 228 项测试；另有 5 项 Python 测试。覆盖真实战斗到掉落、拾取、装备、属性与任务完成的链路。主场景 headless 启动通过。图形交互、复杂碰撞布局与平台导出仍需专项验证。
